# サークルサイト HOME — 320px以上のレスポンシブ版

`index.html` をブラウザで開くと表示できます。配布するサイトは `index.html`、`styles.css`、`connect.css`、`refinements.css`、`about-reveal.js`、`section-overlap.js`、`activity-reveal.js`、`activity-list-reveal.js`、`activity-flow.js`、`news-reveal.js`、`connect-reveal.js`、`assets/` で動作します。各セクションの表示演出、ABOUT／ACTIVITY境界用の高さ計測、ACTIVITYの図案の切り替えにJavaScriptを使用しています。JavaScriptが無効でも全情報を表示します。外部UIライブラリ・ビルド工程・外部への実行時リクエストはありません。

## 全体のデザイン比較案を採用

`refinement-study.html` のデザインを現行HOMEへ採用しました。ABOUTの輪の線画・青い見出し後半・リンクの細い線、ACTIVITYの3つの活動図と背景の円弧、NEWSの細い罫線と小さな輪、白背景CONNECTの輪の線画を反映しています。比較専用の「現行デザインを見る」は持ち込まず、ページ先頭へのリンクを維持しました。灰色のトップ、掲載文章、既存の青幕・スロット・各セクションの表示処理は維持しています。

`refinements.css` は採用した装飾と文字組みだけに限定し、`.home-refined` のページで適用します。ABOUTの見出しは `clamp(25px,2.8vw,54px)`、元の2フレーズを別行にします。輪の線画はABOUTでは1100px未満、CONNECTでは1200px未満で省略します。ACTIVITYの図案は最大440px、1200px未満では360px、800px未満では340pxです。横幅1200px以上かつ画面高760px未満では省略し、左側の文章を優先します。これらは比較案で採用した調整値です。

`activity-flow.js` は既存スロットの選択番号だけを監視します。図420ms・ラベル360msのクロスフェードと80msの開始差、矢印420msの流れを使います。逆方向にも対応し、素早い往復では前の流れをキャンセルします。スクロール位置・距離・滞在時間には干渉しません。初期表示や途中リロードで不要な矢印の再生をせず、モーション軽減時は即時切り替えです。JavaScriptなしでも本文と図を表示します。

`tools/verify-refinement-adoption.cjs` は320〜1920pxの11幅で比較案と採用版の各セクションの画像一致、採用前からの本文・灰色トップの維持、ABOUTの文字色とカバー色、フォールバックを確認します。`tools/verify-refinement-flow.cjs --adopted` は採用版の順方向・逆方向・素早い往復・途中リロードを確認します。記録は `evidence/refinement-adoption/`、採用前のファイルは `evidence/before-refinement-adoption/` です。既存の比較案はそのまま残しています。

Figmaの前回の白背景CONNECTは反映済みですが、今回の全体の線画・見出し変更は未反映です。2026-11-06、Figma MCPからStarterプランのツール利用上限が返され、ファイルの読込・更新を進められませんでした。

## 実装と対応範囲

- 1440pxを比率の基準にしています。ページやセクションに1440pxの最大幅は設けていません。
- 320px以上が設計・検証対象です。800px以上の版に、320〜799px向けのレイアウトを追加しました。
- 親の幅、左右余白、カラム、gapを `%`・`vw`・Gridの `fr` で調整します。
- 本文は `clamp(15px, 1.111111vw, 20px)`。1440pxでは16pxです。見出しも元サイズを基準に `clamp()` で変化します。
- 本文の行高は1.8125、字間は.01em。主要な日本語見出しは行高1.305556、字間.1emで、基準の印象を保ちます。
- 読み幅はABOUT最大36em（1100px未満38em）、ACTIVITY導入27.5625em（1200px未満38em）・一覧35em、CONNECT32emです。段組み全体は広がり、長文の行だけを制限します。
- セクション・活動項目・ニュース行・参加案内の高さは内容で決まります。ページ全体を固定高で切り取る処理は外しました。
- 通常の文章・見出し・CTAはGrid・Flexboxと通常フローへ移しています。縦ラベル、罫線、背景の配置にabsoluteを使用します。
- ACTIVITYのScroll装飾は現在、一時的に非表示にしています。占有していた余白も残りません。再表示する場合は `index.html` の `.scroll-mark` から `hidden` を外します。CONNECTの区切り線はカードの高さに追従し、1カラムでは横線になります。

## CONNECTの初回表示アニメーション

CONNECTは比較案の白背景デザインを採用しました。`connect.css` にこのセクションだけの配色・文字組み・余白を定義しています。大きな左揃えの見出し、罫線で区切る2つの案内、輪郭の矢印を使います。比較用の「現行デザインを見る」は製品ページへ持ち込まず、末尾はページ先頭へのリンクにしています。今回採用した輪の線画は `refinements.css` で追加しています。冒頭の灰色の仮画像は維持し、サークル名やトップのデザインは未作成です。

`tools/verify-connect-adoption.cjs` で320〜1920pxの11幅を確認し、CONNECTが比較案と同じ寸法・書体・配色であること、その他の配置・本文・共通CSS／演出スクリプトが変わっていないことを検証します。記録と画面幅1440pxでのFigma照合用寸法は `evidence/connect-adoption/` に保存しています。新しい数値は比較案で採用した実装調整値です。

FigmaのHOME内の[CONNECT](https://www.figma.com/design/srbX3UDh1xeelbKFRtCbaQ/?node-id=9-21)も1440px基準で更新しました。文字・罫線・矢印は編集できるレイヤーで、案内カードは2つのコンポーネントインスタンスです。旧CONNECTは非表示で残し、その他のセクションと灰色のトップは維持しました。カードとフォントの描画をWebと比較し、見出しの600ウェイトも反映しています。フレーム下端が新しいCONNECTを切り取らないよう、HOMEの高さだけ延長しています。

`connect-reveal.js` はCONNECT内だけを対象とします。白背景・罫線は静止させ、小さなCONNECT文字を下から上へ350msでクリップ表示します。大見出しはABOUTと同じ、実際の文字の描画範囲に合わせた文字色のCover Slide（600ms、160ms後開始、折り返し時は行ごとに140msずつ）です。補足文は480ms後から350msでフェードします。採用したデザインの文字サイズ・余白・文章を演出で動かしません。

左右の案内は見出し・本文を一緒に12pxのFade Up（400ms）、ボタンを100ms遅らせたフェード（350ms）で表示します。案内の開始は中央見出しの表示途中（520ms＋追加行数×140ms後）から可能とし、すべての表示完了や追加スクロールを待たせません。画面内にある案内だけを再生するため、2カラムでは左右同時、1000px未満の1カラムでは各案内が画面に入るタイミングで個別に再生します。

開始位置は画面高の85%が目安です。スクロール位置の変更・固定・ロックは追加していません。各要素はページ表示ごとに1回だけ再生し、表示済みの情報は再び隠しません。JavaScript無効・Intersection Observer非対応・モーション軽減時は通常表示です。高速通過・途中表示・サイズ変更・タブ非表示・終了イベント欠落でも非表示を残さないようにしています。数値はFigma指定値ではなく今回の試作用調整値です。

`tools/verify-connect.cjs` で320〜1920pxの代表9幅の配置と画像比較、390／800／1440／1920pxの演出順・1回再生・文字位置、10種類のフォールバックを検証します。記録とスクリーンショットは `evidence/connect/` に保存します。

NEWSとCONNECTは、フォントとpageshow後の2描画フレームを待ってから開始位置を判定します。ACTIVITY途中のリロードでブラウザが一時的な位置を経由して復元する際に、下のセクションの演出を消費しないためです。タブ非表示・ページ離脱時も未登場の要素は待機を保ち、再生中の要素だけを完了します。復帰後は再び位置が安定してから判定します。フォントの完了通知が来なくても2.5秒後に現在のフォントで準備を進め、未表示の演出を完了扱いにはしません。`tools/verify-downstream-entry.cjs` でACTIVITY中の通常表示・リロード・タブ復帰・ページ復帰・幅変更・フォント通知停止と、その後の各セクションでの再生を確認します。ACTIVITYのスクロール処理とページの配置は変更していません。

## ABOUTの初回表示アニメーション

Intersection ObserverでABOUTの大見出しが画面に入るタイミングを検出し、ページ表示ごとに1回だけ再生します。セクションの大きな上余白では発火させません。再生後は監視・イベントリスナーと演出用属性を解除し、再スクロールで再生しません。

| 要素 | 開始 | 長さ | 動作 |
| --- | ---: | ---: | --- |
| Aboutラベル | 0ms | 350ms | clip-pathで画面上の上から下へ表示。デスクトップの90度回転を考慮 |
| ラベル横の細い線 | 350ms | 350ms | Aboutの表示完了直後に、同じclip-pathアニメーションを開始 |
| 大見出し | 1行目100ms、以降140msずつ遅らせる | 各行600ms | 各行のbeforeの紙色マスクとafterの見出し色の帯で、左から右へ通過後に文字を表示 |
| 本文 | 640ms + 追加行数 × 140ms | 400ms | Fade Up：12px下から元の位置へ移動し、opacity 0 → 1 |
| Learn More | 840ms + 追加行数 × 140ms | 350ms | 本文フェード後半からopacity 0 → 1 |

ABOUTのアニメーション自体は幅・高さ・余白・フォントや、文章のレイアウト上の配置を変更しません。アニメーションで動かすのはclip-path、擬似要素のtransform／opacity、本文のtranslateY（12px → 0）とopacity、リンクのopacityだけです。本文の移動はtransformなので周囲の配置は動きません。モーション軽減設定では本文の移動も無効です。ACTIVITY左側への追加演出は後述します。ACTIVITYのScrollは引き続き非表示です。

見出し全体を覆う大きなカバーをやめ、実際に表示された行ごとの文字の描画範囲に合わせています。Rangeで改行位置と文字位置を取得し、フォント読込後のCanvas文字メトリクスで幅・高さを測ります。アンチエイリアスを覆うための各辺0.5pxだけを加え、行間や末尾の字間の空白は含めません。元の見出しテキストは組み替えず、各行の位置に一時的なaria-hiddenの演出用要素を重ね、そのbefore / afterを動かします。色はcurrentColorで見出し色に追従します（現在は #414141）。表示が1行になる画面幅では、1行分のアニメーションになります。

- JavaScriptが設定を完了するまで、CSSの既定表示は全情報を表示する状態です。JavaScript無効・Intersection Observer非対応・初期化エラーでも情報を隠しません。
- prefers-reduced-motion: reduceでは即時表示し、設定が途中で変わった場合も表示を完了します。CSS側にも即時表示の対応があります。
- 素早いスクロールで見出しを通り過ぎた場合、途中再生中を含め、全情報を即時表示して終了します。Intersection Observerが交差を検出できない画面外へのジャンプは、再生完了までの一時的なpassive scrollリスナーで補います。
- タブを隠す・ページを離れる場合も表示を完了します。animationendが届かない場合は、再生開始から1500ms + 追加行数 × 140msで必ず表示状態に戻します。フォント読込待ちも2500msで打ち切って全表示に戻します。
- 待機中の幅変更では行の範囲を測り直し、再生中の幅変更では即時に表示を完了します。古い位置のカバーが文字を覆い続けることを防ぎます。

[ABOUT演出の専用検証結果](evidence/about-animation/verification.json) と、追加前のソース `evidence/before-about-animation/` を保存しています。実際の動きは `index.html` を開いて確認できます。

Chromeで320 / 360 / 375 / 390 / 428 / 480 / 600 / 768 / 800 / 900 / 1024 / 1280 / 1440 / 1600 / 1920pxの15幅を比較し、完了後の画像は追加前と全画素一致しました。ABOUTの各要素と他セクションの位置・寸法・文字サイズ・余白も一致しています。320 / 800 / 1440pxでは再生中の同じ配置と、layout-shiftの発生がないこと、再スクロールで再生回数が増えないことも確認しました。

JavaScript無効、モーション軽減設定、Intersection Observer非対応・初期化エラー、高速スクロールによる通過、再生中の離脱、途中のモーション設定変更、ページ離脱、animationendが届かない場合のタイマー終了を確認しました。すべて最終的に全情報が表示され、ABOUT以外のアニメーションは検出されていません。実機や他のブラウザでの動作確認は行っていません。

行ごとのカバーへの変更後も15幅で完了後の画像と配置が一致しています。320 / 800 / 1440pxでは、行数に合ったカバー数・見出しと同じ色・140msの開始時刻差・文字に合ったサイズを検証しました。待機中と再生中の幅変更も確認しました。変更前の見出し演出のソースは `evidence/before-about-lines/` に保存しています。

## ABOUT → ACTIVITYのスクロール境界

ABOUTとACTIVITYだけを `.about-activity-boundary` で囲み、ABOUTをsticky、ACTIVITYをその前面に配置しています。ACTIVITYの元の淡い青色背景と内容がスクロールに従って上がり、ABOUTを下から覆います。時間で再生するアニメーションやフェードは追加していません。停止時は止まり、上スクロールでは同じ位置関係へ戻ります。

スクロール処理はCSSの `position: sticky` と `z-index` だけです。`section-overlap.js` はResize ObserverでABOUTの高さをCSS変数に渡すための補助で、スクロールのイベント処理は追加していません。ABOUTが画面より高い場合は `min(0px, 100svh - ABOUTの高さ)` を固定位置とし、末尾まで通常どおり読んでから留まるようにします。svh非対応時はvhを使います。

囲みの高さは2セクションの内容で決まり、演出用のダミーのスクロール距離は足していません。デザイン調整として、Learn Moreから青幕までのABOUT下余白を従来より100px増やしました。横幅は変更していません。`--about-extra-bottom-space: 100px` で調整でき、各レスポンシブ設定の元の下余白に加算します。

青幕の上側だけに、高さ12px・最大不透明度6%のグラデーションによる薄い影を追加しています。影は入力を妨げません。stickyの範囲を囲み内に限定し、NEWS以降にはABOUTが残らないようにしています。prefers-reduced-motion: reduceとJavaScript無効時は、重なりのない元の通常スクロールです。ABOUTの既存アニメーション用スクリプトと、青幕の高さ計測用スクリプトは変更していません。

[境界演出の検証結果](evidence/section-overlap/verification.json) と、変更前のHTML／CSS `evidence/before-section-overlap/` を保存しています。

- 320〜1920pxの15幅で、セクション位置・寸法・文章・文字サイズ・色・余白が変更前と一致しました。
- 320×568、320×240、390×844、768×432、800×600、1440×900、1920×600で、段階的な被覆・逆スクロールでの復元・停止中の静止を確認しました。ABOUT末尾リンクが見えて選択できること、NEWS開始後の重なり残りがないこと、全体のページ高と横幅が変わらないことも確認しています。
- JavaScript無効、モーション軽減設定とその途中変更で、通常スクロールへ戻ることを確認しました。既存ABOUT表示演出の専用検証も再実行して通過しました。
- 画像比較では一部のSVG曲線端に微小な色差が出る場合があります。記録した最終比較では320px幅の14画素、最大11/255の差です。SVGやその表示サイズ・色は変更していません。検証では寸法一致に加え、画像差を最大16/255かつ全体の0.01%以下に限定して確認し、完全一致の有無も別途記録しています。

Chromeでの検証です。実機や他ブラウザでは確認していません。

## ACTIVITY左側の登場アニメーション

`activity-reveal.js` は `.activity-heading` 内のActivityラベル、What We Do、キャッチコピー、本文だけを対象にしています。右側の活動一覧は独立した `activity-list-reveal.js` で制御します。ABOUTのキーフレームをそのまま使い、動き・長さ・イージングを揃えています。

| 要素 | 開始 | 長さ | 動作 |
| --- | ---: | ---: | --- |
| Activityラベル | 0ms | 350ms | ABOUTと同じ上から下へのClip Reveal |
| ラベル横の線 | 350ms | 350ms | ラベル完了直後に同じClip Reveal |
| What We Do | 100ms | 各行600ms | 文字色のCover Slide。文字の描画範囲に合わせ、複数行なら140msずつずらす |
| 交流から、新しい可能性を生み出す。 | 640ms + 見出しの追加行数×140ms | 各行600ms | What We Doと同じ行別Cover Slide。背景側のマスクは青幕と同色 |
| 本文 | キャッチコピーの最終行の開始から540ms後 | 400ms | 12px下からFade Up |

## ACTIVITY右側のスロット表示

`activity-list-reveal.js` がPCの右側一覧を、スクロールのしきい値で切り替わるスロットとして表示します。主役の項目の番号と日本語見出しの文字上端を、左側「交流から、」の文字上端に揃えています。最初はLearningだけが登場し、Meet UpとTryは隠して待機します。しきい値を超えると次の項目が初登場し、右側だけが定位置まで滑らかに移動します。操作を止めても切り替えは完了し、中間位置には留まりません。表示済みの項目を戻る際は登場演出を再生し直しません。ページ全体のスクロール位置の補正、スクロールロック、独立したスクロールバーは使いません。

各項目の初登場は次の順序です。本文が表示し終わってから、その項目の登場演出を完了します。

| 部分 | 開始 | 長さ | 動き |

| 番号 | 0ms | 250ms | opacityのFade |
| 英語名・日本語見出し | 100ms | 各行600ms | ABOUTと同じCover Slide。文字色の帯を、文字の描画範囲に合わせる |
| 本文・区切り線 | 480ms | 350ms | opacityのFade |

見出しが複数行の場合は行ごとに140msずらし、本文の開始も追加行数×140msだけ遅らせます。通常は約830msで1項目の表示が完了します。02・03はスクロールから求めた進行がそれぞれ0.45・1.45へ達した時点で始めます。同時に右側の定位置への移動を開始し、番号・見出し・本文の既存演出を再生します。スクロールを止めても移動と初登場は自動で完了し、次の項目は次のしきい値を超えるまで始まりません。高速移動で項目を飛び越えた場合は、通過項目を全表示へ完了して最新の項目を表示します。
