# サークルサイト HOME — 320px以上のレスポンシブ版

`index.html` をブラウザで開くと表示できます。配布するサイトは `index.html`、`styles.css`、`about-reveal.js`、`section-overlap.js`、`assets/` で動作します。ABOUTの表示演出と、ABOUT／ACTIVITY境界用の高さ計測にJavaScriptを使用しています。JavaScriptが無効でも全情報を表示します。外部UIライブラリ・ビルド工程・外部への実行時リクエストはありません。

## 実装と対応範囲

- 1440pxを比率の基準にしています。ページやセクションに1440pxの最大幅は設けていません。
- 320px以上が設計・検証対象です。800px以上の版に、320〜799px向けのレイアウトを追加しました。
- 親の幅、左右余白、カラム、gapを `%`・`vw`・Gridの `fr` で調整します。
- 本文は `clamp(15px, 1.111111vw, 20px)`。1440pxでは16pxです。見出しも元サイズを基準に `clamp()` で変化します。
- 本文の行高は1.8125、字間は.01em。主要な日本語見出しは行高1.305556、字間.1emで、基準の印象を保ちます。
- 読み幅はABOUT最大36em（1100px未満38em）、ACTIVITY導入27.5625em（1200px未満38em）・一覧35em、CONNECT32emです。段組み全体は広がり、長文の行だけを制限します。
- セクション・活動項目・ニュース行・参加案内の高さは内容で決まります。ページ全体を固定高で切り取る処理は外しました。
- 通常の文章・見出し・CTAはGrid・Flexboxと通常フローへ移しています。縦ラベル、罫線、背景の配置にabsoluteを使用します。
- ACTIVITYのScroll装飾は現在、一時的に非表示にしています。占有していた余白も残りません。再表示する場合は `index.html` の `.scroll-mark` から `hidden` を外します。CONNECTの区切り線はカードの高さに追従し、1カラムでは横線になります。
- 元の文章、配色、セクション順、SVG素材を維持しています。リンク先が未指定の4リンクは引き続き表示のみです。
- スマホではセクション名を横向きにし、本文の読み幅を確保します。本文は15pxのまま、左右余白は20〜40px、主要見出しは24〜28px、セクション間の余白は40〜64pxに調整します。
- 600px未満ではACTIVITYの活動名と説明も上下に配置します。番号と英字の活動名を同じ行に並べ、文章のカラムを狭めません。
- スマホのリンク・ボタンは高さ44px以上です。見出しの行分けを調整し、CONNECTの見出しは必要な幅で「新しい出会いを、」と「ここから」の間で折り返します。

| セクション | 切り替え |
| --- | --- |
| ABOUT | 1100px未満で読み幅と左右余白を組み替え、見出しを自然に折り返す |
| ACTIVITY | 1200px未満で導入と活動一覧を上下に配置。活動名と説明の内側2カラムは800pxでも維持 |
| NEWS | 1000px未満でEVENT・日付の次の行に本文を配置 |
| CONNECT | 1000px未満で学生向け・パートナー向けを上下に配置 |
| スマホ全体 | 800px未満でセクション名を横向きにし、左右余白と文字サイズを調整 |
| ACTIVITYの内側 | 600px未満で活動名と説明を上下に配置 |
| ABOUTの見出し | 480px未満で元の2つのフレーズをそれぞれ1行として配置 |

## ABOUTの初回表示アニメーション

Intersection ObserverでABOUTの大見出しが画面に入るタイミングを検出し、ページ表示ごとに1回だけ再生します。セクションの大きな上余白では発火させません。再生後は監視・イベントリスナーと演出用属性を解除し、再スクロールで再生しません。

| 要素 | 開始 | 長さ | 動作 |
| --- | ---: | ---: | --- |
| Aboutラベル | 0ms | 350ms | clip-pathで画面上の上から下へ表示。デスクトップの90度回転を考慮 |
| ラベル横の細い線 | 350ms | 350ms | Aboutの表示完了直後に、同じclip-pathアニメーションを開始 |
| 大見出し | 1行目100ms、以降140msずつ遅らせる | 各行600ms | 各行のbeforeの紙色マスクとafterの見出し色の帯で、左から右へ通過後に文字を表示 |
| 本文 | 640ms + 追加行数 × 140ms | 400ms | Fade Up：12px下から元の位置へ移動し、opacity 0 → 1 |
| Learn More | 840ms + 追加行数 × 140ms | 350ms | 本文フェード後半からopacity 0 → 1 |

幅・高さ・余白・フォントや、文章のレイアウト上の配置は変更していません。アニメーションで動かすのはclip-path、擬似要素のtransform／opacity、本文のtranslateY（12px → 0）とopacity、リンクのopacityだけです。本文の移動はtransformなので周囲の配置は動きません。モーション軽減設定では本文の移動も無効です。他のセクションにはアニメーションを設定していません。ACTIVITYのScrollは引き続き非表示です。

見出し全体を覆う大きなカバーをやめ、実際に表示された行ごとの文字の描画範囲に合わせています。Rangeで改行位置と文字位置を取得し、フォント読込後のCanvas文字メトリクスで幅・高さを測ります。アンチエイリアスを覆うための各辺0.5pxだけを加え、行間や末尾の字間の空白は含めません。元の見出しテキストは組み替えず、各行の位置に一時的なaria-hiddenの演出用要素を重ね、そのbefore / afterを動かします。色はcurrentColorで見出し色に追従します（現在は #414141）。表示が1行になる画面幅では、1行分のアニメーションになります。

- JavaScriptが設定を完了するまで、CSSの既定表示は全情報を表示する状態です。JavaScript無効・Intersection Observer非対応・初期化エラーでも情報を隠しません。
- prefers-reduced-motion: reduceでは即時表示し、設定が途中で変わった場合も表示を完了します。CSS側にも即時表示の対応があります。
- 素早いスクロールで見出しを通り過ぎた場合、途中再生中を含め、全情報を即時表示して終了します。Intersection Observerが交差を検出できない画面外へのジャンプは、再生完了までの一時的なpassive scrollリスナーで補います。
- タブを隠す・ページを離れる場合も表示を完了します。animationendが届かない場合は、再生開始から1500ms + 追加行数 × 140msで必ず表示状態に戻します。フォント読込待ちも2500msで打ち切って全表示に戻します。
- 待機中の幅変更では行の範囲を測り直し、再生中の幅変更では即時に表示を完了します。古い位置のカバーが文字を覆い続けることを防ぎます。

[ABOUT演出の専用検証結果](evidence/about-animation/verification.json) と、追加前のソース `evidence/before-about-animation/` を保存しています。実際の動きは `index.html` を開いて確認できます。

Chromeで320 / 360 / 375 / 390 / 428 / 480 / 600 / 768 / 800 / 900 / 1024 / 1280 / 1440 / 1600 / 1920pxの15幅を比較し、完了後の画像は追加前と全画素一致しました。ABOUTの各要素と他セクションの位置・寸法・文字サイズ・余白も一致しています。320 / 800 / 1440pxでは再生中の同じ配置と、layout-shiftの発生がないこと、再スクロールで再生回数が増えないことも確認しました。

JavaScript無効、モーション軽減設定、Intersection Observer非対応・初期化エラー、高速スクロールによる通過、再生中の離脱、途中のモーション設定変更、ページ離脱、animationendが届かない場合のタイマー終了を確認しました。すべて最終的に全情報が表示され、ABOUT以外のアニメーションは検出されていません。実機や他のブラウザでの動作確認は行っていません。

行ごとのカバーへの変更後も15幅で完了後の画像と配置が一致しています。320 / 800 / 1440pxでは、行数に合ったカバー数・見出しと同じ色・140msの開始時刻差・文字に合ったサイズを検証しました。待機中と再生中の幅変更も確認しました。変更前の見出し演出のソースは `evidence/before-about-lines/` に保存しています。

## ABOUT → ACTIVITYのスクロール境界

ABOUTとACTIVITYだけを `.about-activity-boundary` で囲み、ABOUTをsticky、ACTIVITYをその前面に配置しています。ACTIVITYの元の淡い青色背景と内容がスクロールに従って上がり、ABOUTを下から覆います。時間で再生するアニメーションやフェードは追加していません。停止時は止まり、上スクロールでは同じ位置関係へ戻ります。

スクロール処理はCSSの `position: sticky` と `z-index` だけです。`section-overlap.js` はResize ObserverでABOUTの高さをCSS変数に渡すための補助で、スクロールのイベント処理は追加していません。ABOUTが画面より高い場合は `min(0px, 100svh - ABOUTの高さ)` を固定位置とし、末尾まで通常どおり読んでから留まるようにします。svh非対応時はvhを使います。

囲みの高さは元の2セクションの合計のままで、余白やスクロール用の空白は足していません。stickyの範囲を囲み内に限定し、NEWS以降にはABOUTが残らないようにしています。prefers-reduced-motion: reduceとJavaScript無効時は、重なりのない元の通常スクロールです。ABOUTの既存アニメーション用スクリプトは変更していません。

[境界演出の検証結果](evidence/section-overlap/verification.json) と、変更前のHTML／CSS `evidence/before-section-overlap/` を保存しています。

- 320〜1920pxの15幅で、セクション位置・寸法・文章・文字サイズ・色・余白が変更前と一致しました。
- 320×568、320×240、390×844、768×432、800×600、1440×900、1920×600で、段階的な被覆・逆スクロールでの復元・停止中の静止を確認しました。ABOUT末尾リンクが見えて選択できること、NEWS開始後の重なり残りがないこと、全体のページ高と横幅が変わらないことも確認しています。
- JavaScript無効、モーション軽減設定とその途中変更で、通常スクロールへ戻ることを確認しました。既存ABOUT表示演出の専用検証も再実行して通過しました。
- 画像比較では一部のSVG曲線端に微小な色差が出る場合があります。記録した最終比較では320px幅の14画素、最大11/255の差です。SVGやその表示サイズ・色は変更していません。検証では寸法一致に加え、画像差を最大16/255かつ全体の0.01%以下に限定して確認し、完全一致の有無も別途記録しています。

Chromeでの検証です。実機や他ブラウザでは確認していません。

## 再検証と過去の記録

`tools/verify.cjs` は開発用で、サイトからは読み込みません。Node.js、Playwright、sharp、およびインストール済みChromeが必要です。この環境ではCodex付属ライブラリを使用します。

```powershell
$env:CODEX_NODE_MODULES = 'C:/Users/yuta0/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules'
node tools/verify.cjs

# スマホ8幅と既存7幅、追加前との画像一致も確認
node tools/verify.cjs --mobile

# ABOUTの表示演出・フォールバック・レイアウトの非変更を確認
node tools/verify-about.cjs

# 境界の重なり・逆スクロール・操作性とレイアウト維持を確認
node tools/verify-section-overlap.cjs
```

通常のNode.js環境でPlaywright・sharpを解決できる場合、環境変数は不要です。通常モードは `evidence/responsive/`、`--mobile` は `evidence/mobile/` に画像・縮小一覧・検証JSONを出力します。`--mobile` は `evidence/before-mobile/` の7幅の画像との比較値も記録します。これらの過去画像にはScroll誘導があるため、現在は画像一致自体を成否判定に含めていません。

初回固定版のソース・画像・検証値は `evidence/baseline/` に保存しています。`evidence/asset-map.json` と `evidence/verification.json` は初回固定版の記録です。`evidence/comparison.html` も初回固定版とFigmaの比較として残しています。800px以上の対応記録は `evidence/responsive/`、今回のスマホ対応の結果は `evidence/mobile/` を参照してください。
